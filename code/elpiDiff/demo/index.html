elpiDiff in the browser

Write a Julia program and get the Julia program of its derivatives, in tangent (forward) and adjoint (reverse) mode: every function of the program is differentiated, the rest (using, comments, top-level code) is ignored. The work is done by elpiDiff, an automatic differentiation tool written in Elpi, here running inside your browser: Elpi is compiled to WebAssembly and the Julia code is parsed by tree-sitter. Nothing is sent to a server, and nothing is evaluated: the output is a program.

How to read the generated code
  • Tangent f_tangent(x, x_dot): the arguments, then a tangent for each argument that carries one. It returns the value of f and the tangent of the result.
  • Adjoint-value f_adjoint_value(x, x_bar, result_bar): the arguments, the adjoints to accumulate into, and the seed result_bar. It runs f forward (its value), recording on a tape only what the reverse sweep needs (to-be-recorded analysis), then the reverse sweep. Start every x_bar at 0: it returns the value of f and x_bar + result_bar * f′(x) (an array x_bar is updated in place).
  • Returned values: Julia passes reals by value, so a real output is returned: a tuple of the result, if any, then each real output in the order of the arguments.
  • Arrays: an array output is updated in place (pass a Vector or an MVector); an array passed by value is copied first.
  • Which arguments: under the program, each function lists its arguments; uncheck one to make it passive (a parameter, not differentiated: no x_dot, no x_bar). An Int, a Bool or an array the function writes cannot be chosen.
  • Indices: the loops count from 0, as in the tool's intermediate language, and a[i] is printed a[i + 1].

What the front end accepts (anything else is refused, with the reason):

  • a program: any number of functions function f(…) … end and f(…) = … (other top-level statements are ignored); assignments x = …, x += …, a[i] = …;
  • if/elseif/else that sets one variable, or ends the function with a value on both branches; c ? a : b;
  • for i in lo:hi that writes y[i] of an array it never reads, or updates one variable;
  • + - * /, comparisons, x^k with an integer literal k, sin cos exp log sqrt;
  • arguments: reals (no annotation, Real, Float64), Int and Bool (not differentiated), SVector{N} (input array), MVector{N} (array the function writes); a real or an input array can be unchecked under the program to keep it passive.

Not accepted, for example: while, tuples, a loop or branch that sets several variables, chained comparisons, &&, keyword arguments.
